# Utilisation de la grille RAF20.tac

Exemple d'utilisation de la grille RAF20.tac téléchargeable depuis [cette page](https://geodesie.ign.fr/grilles-de-conversion) permettant de passer d'altitude à hauteur au dessus de l'ellipsoïde. Le format de cette grille est détaillée [ici](https://www.ign.fr/publications-de-l-ign/Geodesie/pdf/Grilles-MNT-TXT_Formats.pdf).  
Le script `raf20.py` fournit un exemple d'utilisation de cette grille.
